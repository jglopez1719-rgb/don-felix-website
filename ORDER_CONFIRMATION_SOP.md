# Don Felix text-order confirmation SOP

**For:** Family members and staff answering text orders  
**Version:** September 16, 2026  
**Goal:** Every customer receives a clear, accurate answer and knows whether the order is actually confirmed.

## The one rule

A customer’s first text is an order request—not a confirmed order. The order becomes confirmed only after someone from Don Felix checks availability and sends a message that includes the words **“Your order is confirmed.”**

## When an order text comes in

1. Read the entire message.
2. Make sure it includes:
   - Customer name
   - Item
   - Quantity or size
   - Pickup day
   - Pickup time
3. Check the butcher case, BBQ supply or kitchen supply before promising the item.
4. Check that the requested pickup time is possible.
5. Confirm the unit price. Remember:
   - Chicken breast and chicken legs are sold by the piece.
   - Chicken wings and BBQ beef are sold by the pound.
   - Meat sold by weight may have a slightly different final total once it is weighed.
   - Website prices are before tax.
6. Send either the **confirmed**, **need more information** or **unavailable** reply below.
7. Write the confirmed order in the store’s order log immediately.

## Copy-and-paste replies

Replace everything inside brackets before sending.

### Confirmed order

> Hi [CUSTOMER NAME], your order is confirmed for [DAY] at [TIME]: [QUANTITY] of [ITEM]. The price is [UNIT PRICE], and the estimated subtotal is [SUBTOTAL] before tax. [FOR WEIGHED MEAT: The final total may change slightly based on the actual weight.] Please reply here if you need to change anything. Thank you—Don Felix Meat Market.

### Need more information

> Hi [CUSTOMER NAME], thank you for reaching out to Don Felix. Before we confirm it, what [QUANTITY / SIZE / PICKUP DAY / PICKUP TIME] would you like?

### Item is unavailable or sold out

> Hi [CUSTOMER NAME], we are sorry, but [ITEM] is not available for [DAY/TIME]. We can offer [ALTERNATIVE] instead, or we can check another pickup time. Would either option work for you?

### Order is ready

> Hi [CUSTOMER NAME], your Don Felix order is ready for pickup. Please ask for the order under [NAME] when you arrive. We are at 3987 Sawtelle Blvd.

### Change confirmed

> Hi [CUSTOMER NAME], we updated your order to [NEW DETAILS]. Your order is confirmed for [DAY] at [TIME].

### Cancellation confirmed

> Hi [CUSTOMER NAME], your order for [DAY] at [TIME] has been canceled. Thank you for letting us know.

Only write the last four digits of the customer’s phone number in a paper or shared order log.

## Before the pickup time

1. Recheck the order log.
2. Prepare and label the order with the customer’s first name and pickup time.
3. Verify the item, quantity or weight, and size.
4. If the final weight or price changes, tell the customer before pickup when possible.
5. Mark the order **ready** and send the ready message.

## At pickup

1. Ask for the customer’s name.
2. Read the order back before payment.
3. Confirm the final price and tax.
4. Mark the order **picked up**.
5. Thank the customer.

## If something goes wrong

- Never mark an order confirmed without checking availability.
- Never promise an exact final price for meat sold by weight before it is weighed.
- Never promise that an item is allergen-free unless the owner has personally confirmed it.
- If an order will be late or unavailable, contact the customer immediately and offer the closest honest alternative.
- If a customer is upset or asks for a refund, involve Juan or Graciela.

## Weekly five-minute review

Once a week, write down:

- Number of confirmed text orders
- Number of sold-out requests
- Most-requested item
- Most-requested pickup window
- Questions customers kept asking
- Any order mistakes and how to prevent them next week

Compare this short store log with the website analytics. Website analytics show taps and order-builder activity; the store log shows which requests became real, completed orders.
